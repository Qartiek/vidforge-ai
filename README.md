# VidForge AI

AI-powered YouTube content creation and automation SaaS - from idea to publish.

## Current foundation
- Next.js + TypeScript web app
- Public landing page
- Creator dashboard
- Pricing foundation
- Super Admin foundation
- Modular content production pipeline
- API health endpoint
- Project creation API foundation

## Production pipeline
Research -> Hook -> Script -> Voice -> Visuals -> Edit -> Thumbnail -> SEO -> Publish

## Initial niche
Company finance and business analysis, with a modular architecture for additional niches.

## Security direction
Provider secrets stay server-side. Authentication, database persistence, billing, job queues, rate limits, audit logs and provider integrations are planned as backend layers.

## Status
MVP foundation - under active development.
